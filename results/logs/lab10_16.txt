5. When is each environment appropriate?
------------------------------------------------------------------------------
| environment      | interface                                    | good for                                  | limitation                                                 |
|------------------|----------------------------------------------|-------------------------------------------|------------------------------------------------------------|
| RSIGym (EaaS)    | typed services + shared budget + permissions | fair, metered comparisons; many improvers | the agent cannot do anything the services do not expose    |
| Terminal-RSI     | shell + files + CLI                          | agents that write and run code freely     | needs an OS sandbox; budgets and splits are by convention  |
| R2Orch self-play | a task proposer + the solver population      | curriculum discovery without labels       | learnability rewards can drift toward easy-but-noisy tasks |
