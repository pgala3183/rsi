The gap is identical with the diagnostics switched off. Where does it come from?
  so_rsi_demo.py:203: outcome = "success" if random.random() < 0.3 else "failure"
  so_rsi_demo.py:249: outcome = "success" if random.random() < 0.5 else "failure"
  so_rsi_demo.py:300: expected = "success" if random.random() < 0.3 else None
  so_rsi_demo.py:344: expected = "success" if random.random() < 0.3 else None
-> the success probabilities are hard-coded (0.3 vs 0.5). Diagnostics never change the next fix
   (see the comment 'In full implementation, this would adjust the fix strategy').

  first-ever failure, empty history -> anomalies ['recurrence']
